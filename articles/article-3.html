Type Coercion

JavaScript automatically performs type coercion. 

console.log("5" + 3);      // "53"
console.log(true + 1);     // 2
console.log(0 == false);   // true

Python requires explicit conversion for most types. 

print("5" + 3)       # TypeError
print("5" + str(3))  # "53"
print(True + 1)      # 2
print(0 == False)    # True
print(int("42"))     # 42
print(float("42"))   # 42.0
