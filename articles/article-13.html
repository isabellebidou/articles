n8n

n8n is a workflow automation tool that allows you to automate tasks and processes by creating workflows that connect different applications and services. It is an open-source tool that can be self-hosted or used in the cloud.

I chose to implement the Docker setup. I have been wanting to experiment with Docker for a while.

The setup is the following: you need to download Docker, installed it. Because I didn't want to take a chance with missing my PATH I also chose to temporarily add the docker-path to the current terminal session.

local installation with Docker

  • # Download and install Docker Desktop from the official website.
  • # Open Docker Desktop
  • # 1 Check that Docker is running and that the Docker daemon is active.
  • add the path globally or temporarily add the docker-path to the current terminal session
  • # docker --version
  • # docker ps
  • # 2 Create persistent storage
  • # docker volume create n8n_data => you should see 'n8n_data'
  • # 3 Create and start your n8n container
  • // download  create and start 
  docker run -d \
  --name n8n \
  --restart unless-stopped \
  -p 127.0.0.1:5678:5678 \
  -e TZ=Europe/Paris \
  -e GENERIC_TIMEZONE=Europe/Paris \
  -e N8N_ENFORCE_SETTINGS_FILE_PERMISSIONS=true \
  -e N8N_RUNNERS_ENABLED=true \
  -v n8n_data:/home/node/.n8n \
  docker.n8n.io/n8nio/n8n
  • # 4check the container is running with 
    docker ps
  • # 5 Access the web interface with 
    http://localhost:5678
    in your browser.

Usage once the first set up is done

  • # Start Docker Desktop first
  • Open 
    http://localhost:5678
    in your browser.

I choose never to stop the container because I want to be able to stop it or start it just by opening the Docker application. Whenever I want to work locally on n8n I just open Docker and all my workflows are available.

Webhooks

Among the many benefits and uses of the vast array of nodes available with n8n, webhooks caught my attention. They are a way for applications to communicate with each other in real-time. They allow one application to send data to another application when a specific event occurs. In the context of n8n, webhooks can be used to trigger workflows based on events from external services or applications. For example, you can set up a webhook in n8n that listens for incoming HTTP requests and triggers a workflow whenever a request is received. This allows you to automate tasks and processes based on real-time events, making your workflows more dynamic and responsive. I have a platform where users sign in using their Google account. When a user signs in for the first time a new account is created and the new user is stored on my MongoDB database. New users have a limited access to the functionalities to my platform. I want to review each profile before granting them full access. I have set up a webhook in n8n that listens for new user sign-ups and triggers a workflow that sends me an notifications with the user's details. This allows me to review the new user's profile and decide whether to grant them full access or not.

Locally I was able to set it up seamlessly using an SMTP node to send emails and a telegram node to send messages. It worked flawlessly.

However when I tried to set it up on Railway I started encountering issues with the email node not functioning as expected. I was unable to establish a connection with gmail. Since this is a simple demo I opted to simplify and lower my ambitions and just sticked to the telegram node in production.
