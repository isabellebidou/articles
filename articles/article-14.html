local LLMs with LM Studio and Pi

LM Studio

LM Studio is a local language model server that allows you to run and manage local language models on your own machine. It provides a user-friendly interface for managing and interacting with language models, and it supports a wide range of models and configurations. It is designed to be easy to use and provides a simple way to run local language models without the need for complex setup or configuration.

Pi

Pi is a command-line interface for interacting with local language model servers. It allows you to perform various tasks such as starting, stopping, and managing language models. Once you start a local language model server with LM Studio you can use Pi to interact with the server and perform tasks such as creatting files in a project and writing code direclty. You just have to write your prompts into the pi interface in your terminal and the model will generate the corresponding code or text based on your prompts.

Pi setup

You will have to install pi first. You can do this in a different ways as explained at https://pi.dev/docs/latest/quickstart , I personnaly chose to use npm. I run the following command in my terminal: npm install -g --ignore-scripts @earendil-works/pi-coding-agent. Once you have installed pi, you need to write a json configuration file to specify the model you want to use and its parameters. The configuration file should be in the following format: 

{
  "providers": {
    // Custom name of the provider
    "lmstudio": {
      "baseUrl": "http://127.0.0.1:1234/v1", // Your LM Studio server URL (with /v1) appended
      "api": "openai-completions", // Use either openai-completions or openai-responses
      "apiKey": "key", // Your api key or any non-empty string if auth is disabled
      "models": [
        {
          "id": "your-loaded-model-id", // Model ID (the only required field in the model configuration)
          "name": "Local Coding Model",// some readable name for the model (optional)
          "contextWindow": XXXXXXX, // Total context size
          "maxTokens": XXXXX, // Max output tokens
          "reasoning": true, 
          "input": ["text", "image"], 
        }
      ]
    }
  }
}

Before you start pi, make sure you are in your project directory. Just type pi in your terminal and you will be able to start interacting with the model. You can also use the pi --continue command to resume your last active session in this workspace.

Pi commands for local language model servers

Action / Context Shortcut / Command Description
🚀 Session Control pi Starts a fresh agent session in the current project directory.
pi --continue Resumes your last active session in this workspace.
/new Wipes the conversation history mid-session to start a completely fresh prompt thread.
🛑 Stop & Exit Escape Instantly stops/aborts a running model generation or a long-running bash tool execution.
/quit or Ctrl + C (x2) Gracefully closes the Pi CLI and returns you to your standard terminal profile.
🤖 Model Control /model or Ctrl + L Opens the model manager interactive menu to browse and pick available local or cloud providers.
Ctrl + S (inside menu) Locks the currently highlighted model as your permanent default startup model.
Ctrl + P Instantly quick-cycles through your favorite pinned ("scoped") models mid-chat.
⚡ Everyday Tips Shift + Tab Cycles through model reasoning/thinking intensity levels (e.g., minimal, low, medium, high).
pi --list-models [provider] Runs diagnostics directly outside the app to check configuration parsing (e.g., lmstudio).
